AlignAtt4LLM

A simultaneous speech-translation system that recovers target-to-source alignment from selected decoder-only LLM attention heads and commits only evidence-supported output.

First author · IWSLT 2026 · Python

Qwen3-ASR-causal

A causal streaming Qwen3-ASR runtime with bounded KV state and append-only transcripts. Each audio block is encoded once, using 3–4× less compute than windowed inference.

Creator · Streaming inference · PyTorch

Creator · Agents · Retrieval
